# MafiaCity — играбельные прототипы

Открытый репозиторий только для страниц, которые публикуются через GitHub Pages:
https://ihavenews4u.github.io/MafiaCityPlay/

- `index.html` — карта с ботами (геолокация, вызов на бой в радиусе 150 м).
- `duel.html` — пошаговая дуэль против бота.
- `bots.js` — список ботов и их координаты.

Правила боя и расчёты баланса живут в закрытом репозитории MafiaCity.
